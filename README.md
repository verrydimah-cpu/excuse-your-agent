A one-line excuse an AI agent gives its human for a bug it shipped: the code did exactly what it was told — by a very confident, completely unsupervised agent. The program writes that single line to entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
